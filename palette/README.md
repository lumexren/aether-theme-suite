# Aether Palette

![Aether Palette Swatches](swatch.svg)

Canonical color palette and typography tokens for **Aether Theme Suite** (`lumexren/aether-theme-suite`).

## Files

- `palette.json` — Machine-readable source of truth (Hex, RGB, HSL, semantic tokens, ANSI 16/24 colors, typography).
- `palette.css` — CSS Custom Properties (`--aether-*`) for GTK, Web, Obsidian, Discord, Waybar, and Electron apps.
- `swatch.svg` — Visual capsule swatches generated from `palette.json`.
